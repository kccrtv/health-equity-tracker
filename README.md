# CHARLIE OCONUS

Create a minimal placeholder React app with a single blank page.

Centered on the page, display the text "CHARLIE OCONUS" as a large heading.

No other content, no navigation, no buttons — just this one page.

Set up a basic design system / theme file (not just inline styles) so it's easy to extend later:

Typography: DM Sans for headings, Inter for body text

Primary brand color: #0B3D3A

Secondary/accent color: #4B3F72

Background: #FFFFFF

Keep the project structure clean and minimal — no extra pages, no sample components, no placeholder content beyond this one screen.

Use Tailwind for styling if that's the default, but pull the actual color/font values into the theme config (tailwind.config) rather than hardcoding them in the component.
